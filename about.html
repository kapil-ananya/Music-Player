About A-Naya Tunes

A-Naya Tunes is a simple and modern web-based music player designed to provide an enjoyable music listening experience. This project is developed using HTML, CSS, and JavaScript.

The player allows users to play, pause, and switch between songs easily. It includes features such as a progress bar, next and previous buttons, and a playlist where users can select any song.

The main purpose of this project is to demonstrate how web technologies can be used to build an interactive music player with a clean and user-friendly interface.
